# Contribuer à Frame Cutter

Les signalements et les propositions de modification sont bienvenus.

- Pour un bug, indiquez la version de Windows, les versions de Python et FFmpeg, les étapes et le résultat attendu. Utilisez une vidéo fictive ou un fichier que vous pouvez partager. Retirez les clés, informations personnelles et liens privés de vos exemples.
- Pour une modification, ouvrez une pull request et expliquez le changement et la vérification effectuée. Le [README](README.md) indique comment lancer les tests.
- Proposez du code et des éléments que vous êtes autorisé à partager. Indiquez la source et la licence de tout élément repris ailleurs.
