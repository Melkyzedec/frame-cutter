# Politique de sécurité

## Signaler une vulnérabilité

Dans GitHub, ouvrez **Security and quality**, puis **Advisories** et **Report a vulnerability**. Le signalement privé permet au mainteneur de vérifier et de corriger le problème avant une éventuelle publication.

Indiquez la version ou le commit de Frame Cutter, votre version de Windows et les étapes de reproduction. Utilisez des données fictives. Évitez de joindre des clés, des données personnelles ou des fichiers privés.

Pour un défaut ordinaire sans enjeu de sécurité, utilisez **Issues**.

## Versions suivies

Les correctifs sont préparés sur la branche principale `main`. Vérifiez si le problème persiste sur cette branche.
