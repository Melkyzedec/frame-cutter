# Composants tiers

La distribution des sources de Frame Cutter référence les prérequis ci-dessous. Chaque outil est installé séparément depuis son projet ou son distributeur. Cette archive contient le code de Frame Cutter et la liste des dépendances. FFmpeg, ffprobe, yt-dlp et Node.js s’exécutent dans des processus séparés.

- Python et Tkinter. [Avis et licences Python](https://docs.python.org/3.14/license.html).
- FFmpeg et ffprobe. La licence dépend de la compilation choisie. [Informations de licence du projet FFmpeg](https://ffmpeg.org/legal.html).
- yt-dlp 2026.10.26. Le paquet PyPI référencé dans [requirements-import.txt](requirements-import.txt) est sous Unlicense. Le projet annonce GPL 3 ou ultérieure pour ses exécutables assemblés avec PyInstaller. [Licences de cette version de yt-dlp](https://github.com/yt-dlp/yt-dlp/blob/2026.10.26/README.md#licensing).
- yt-dlp-ejs 0.8.0. Le paquet contient du code sous Unlicense, MIT et ISC. [Licences de cette version de yt-dlp-ejs](https://pypi.org/project/yt-dlp-ejs/0.8.0/#licensing).
- Node.js, pour l’import YouTube. [Licence et notices du projet Node.js](https://github.com/nodejs/node/blob/main/LICENSE).
